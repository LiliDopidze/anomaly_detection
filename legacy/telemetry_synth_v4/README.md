# Frozen telecom generator

This directory contains the supplied telemetry-synth v4 generator source. It is kept
for lineage, reproducibility and grouped-fault fixture tests; it is not part of the
anomaly-detection runtime package.

Do not modify this source as part of detector, contract, pack or adapter work. A new
generator version must be introduced as a separately versioned frozen directory and
must not silently replace this baseline.
